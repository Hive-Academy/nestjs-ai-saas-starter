**Why Canva for Decorative Elements:**
- ✅ **Complex visual compositions** - Multi-layered graphics with gradients, patterns

- ✅ **Rapid iteration** - 4 design candidates per theme, select best
- ✅ **Transparent backgrounds** - Perfect for overlays at 10-20% opacity
- ✅ **Theme-specific visuals** - Each library gets unique decorative style

**Why Hand-coded SVG for Icons:**
- ✅ **Simple geometric shapes** - Icons are straightforward (circles, lines, paths)
- ✅ **Version control** - Code-based SVGs tracked in git
- ✅ **Instant availability** - No external dependencies
- ✅ **Lightweight** - < 2KB per icon

**Hybrid Approach = Best of Both Worlds**

## Design Decisions

### Why These Specific Visual Styles?

**ChromaDB - Vector Search Visualization:**
- Radiating arrows = semantic search spreading through vector space
- Floating documents = corpus being searched
- Central database = vector storage
- **Visual metaphor**: "Finding related content in all directions"

**Neo4j - Network Graph:**
- Interconnected nodes = graph relationships
- Varying node sizes = importance/centrality
- Curved lines = organic connections
- **Visual metaphor**: "Everything is connected"

**Workflow/Streaming - Data Flow:**
- Horizontal flow = pipeline progression
- Particles = data chunks moving through system
- Processing nodes = transformation stages
- **Visual metaphor**: "Continuous data movement"

## Opacity & Animation Guidelines

**Recommended Opacity Levels:**
- **Primary decorations** (large, prominent): 10-12% opacity
- **Secondary decorations** (smaller, accent): 5-8% opacity
- **Tertiary decorations** (subtle hints): 3-5% opacity

**Scroll Animation Patterns:**
- **fadeInUp**: Bottom corners, suggests emergence
- **fadeInDown**: Top corners, suggests descent
- **fadeInLeft**: Right side, suggests incoming
- **fadeInRight**: Left side, suggests outgoing
- **scaleIn**: Center elements, suggests expansion

**Timing Guidelines:**
- **Duration**: 1.2-1.8 seconds (slower = more elegant)
- **Delay**: Stagger by 0.2-0.4s (create wave effect)
- **Start trigger**: 'top 70-80%' (animation begins before fully in view)
